# C1Max Calendar 0.3

从本地 `~/Workspace/m5stack/CardputerZero/Calendar` 迁移的 800×340 MIPS Linux
日历。复用共享 LVGL 显示、实体键盘和 HTTP 客户端；不创建虚拟键盘，也没有屏幕退出按钮。

## 本轮补齐的管理功能

- 新增、查看、编辑、删除本地日程；删除前确认，离开有修改的表单前确认放弃。
- 全部本地日程列表、所选日期的日程列表和可滚动详情。
- 标题、开始/结束日期、开始/结束时间、全天、地点、备注；校验闰年、日期范围和起止顺序。
- ICS 订阅的新增、编辑、删除、启用/停用、异步同步和本地缓存。
- CardputerZero 原版七个内置外部日历，可直接选择，不必输入网址；默认停用。
- 下载失败或取消同步时保留已有缓存；个人日程与订阅缓存分开保存。
- 将全部本地日程导出为 ICS，包含 UTF-8 文本、转义、75 字节折行及全天结束日期语义。
- 兼容此前放入的 `events.ics`，作为独立只读来源，不会被本地日程编辑覆盖。

原 CardputerZero Calendar 的“管理”主要管理 **ICS 订阅、语言和来源样式**，没有个人日程
新增/编辑界面。这版保留原月历、ICS 展开/筛选逻辑，迁移订阅管理的实用部分，并新增本地日程编辑器。
原来源码未修改。

## 内置外部日历

在月历按 `I` 进入订阅管理，再按 `B` 打开内置列表；也可在 `M` 管理页选择
“内置外部日历”。选择来源后，在编辑页开启“订阅：启用”并保存，再按 `Y` 同步。
触摸和 `W/S` 选择、`Enter` 确认均可用，不创建虚拟键盘。

| 来源 | 与 CardputerZero 相同的服务 |
| --- | --- |
| 中国节假日 / 调休 | 日历 Pro `HoliBack/HoliBack.php` |
| 日本、美国、英国、德国、法国节假日 | Google Calendar 对应国家公开节假日 ICS |
| 黄历 / 每日宜忌 | 日历 Pro `huangli/yi.ics` |

精确 URL 保存在 `calendar_store.cpp` 的 `builtin_sources()`。打开列表不联网，
不修改数据库，也不自动启用任何来源。已有相同 ID 或规范化 URL 的订阅会直接进入
原设置，保留自定义名称、地址与启停状态；不会重复添加。删除后不会在重启时自动出现，
需要时可从内置列表重新添加。所有已下载内容均可离线阅读。

旧 `C1MAX_CALENDAR_V1` 数据格式继续使用；来源容量从 8 提升到 16，旧有八个
自定义订阅之外仍可加入全部七个预设。当地调休和黄历内容由原外部来源提供，
不是应用自行推算；原版的本地近似农历算法不属于本次在线来源迁移。

## 操作

| 场景 | 实体键 |
| --- | --- |
| 所有页面 | 关机键回 launcher；中间返回键只退一层，月历根页面保持原位 |
| 月历 | `W/A/S/D` 前一周/前一天/后一周/后一天；`Q/E` 翻月；`T` 今日 |
| 月历/日程列表 | `N` 新增；`Enter` 查看选定日期或日程 |
| 月历/管理 | `L` 全部本地日程；`I` 订阅；`M` 从月历进入管理 |
| 列表及非文本按钮 | `W/S` 或 `K/J` 选择；`Enter` 确认 |
| 日程详情 | `W/S` 滚动；本地日程的 `E` 编辑、`D` 删除 |
| 表单文本框 | 实体键直接输入；右上退格删除；`Enter` 下一项；触摸可直接选框 |
| 表单按钮 | `W/S` 切换；`Enter` 执行；可直接轻点保存/取消/全天/启停 |
| 管理/订阅 | `Y` 同步启用的订阅；同步时中间返回取消 |
| 管理/订阅 | `B` 内置外部日历；内置页也支持 `Y` 同步 |
| 管理 | `R` 重读本地文件；`X` 导出个人日程为 ICS |

非文本页面的字母快捷键忽略大小写，文本框保留共享驱动提供的大小写。双击 Shift 切换 Caps；
模式变化会显示 `ABC/abc`。数字、标点沿用共享实体键盘映射，不占用 Symbol 键。
表单日期格式 `YYYY-MM-DD`、时间格式 `HH:MM`；全天日程的结束日期包含当天。
没有额外绑定 LVGL keypad，避免与 `screen::take_key()` 重复消费按键。

共享键码契约：`KEY_HOME=0x10002` 表示关机键；`KEY_EXIT=0x10000` 表示中间返回；
右上退格为 `LV_KEY_BACKSPACE`；`KEY_MODE=0x10003` 通知大小写模式变化。
直接按关机键退出不会保存未提交表单；中间返回会先提示放弃修改。

## 数据与同步

默认数据目录 `/storage/apps/data/calendar/`：

| 文件 | 内容 |
| --- | --- |
| `calendar.db` | 本地日程与订阅设置；带版本的 UTF-8 文本格式，不是 SQLite |
| `events.ics` | 用户从电脑导入的旧版只读 ICS |
| `cache-<id>.ics` | 单个在线订阅的最近成功缓存 |
| `export.ics` | 在管理页手动导出的个人日程 |

`calendar.db` 用私有权限的临时文件、`fsync` 和原子 rename 保存。读取失败时禁止覆盖原数据，
并显示错误；失败的编辑保存保留旧文件。删除订阅只删除本机设置与相应缓存，不修改远程服务。
`C1_APPS_ROOT` 和 `C1_APPS_DATA` 可覆盖程序/数据根目录。

内置来源只作为可选目录，不自动联网，不自动启用任何国家的节日。选择预设或添加
ICS/webcal 地址，启用并保存后手动同步。
HTTPS 复用应用包内 CA 校验，不关闭证书校验。URL 和可能包含私人订阅令牌的设置保存在设备私有文件里。
当前 HTTP 客户端不跟随重定向，请填写最终的 ICS 地址；不支持登录式 CalDAV 或向服务器写回日程。
每个来源最多等待约 8 秒，可取消当前同步；最多 16 个来源，逐个处理。

容量限制：最多 256 项本地日程、16 个订阅，数据库不超过 1 MiB；每个 ICS 文件 256 KiB，
每个来源最多展开 512 项日程，总月历窗口最多保留 1024 项（优先保留本地日程）。
标题最多 256 字节、地点 512 字节、备注 4096 字节。超限会显示错误，不覆盖已有数据。

月历导航为 1900–2199 年；公历运算不依赖 32 位 `time_t`，覆盖 2038 年之后。
“今日”使用设备本地时间，应用不修改系统时间。

## 覆盖范围与限制

保留原版左侧月历和所选日期详情、周一开始的 42 日网格、ICS 转义/折行、简单重复规则、
全天和跨日日程。迁移订阅新增/删除/编辑/启停及下载缓存，并新增原版没有的本地 CRUD。

尚未迁移原版多语言切换、每来源边框/背景样式、天气；原版固定 354 天近似农历不显示。
在线黄历已随外部日历预设迁移，显示服务返回的每日宜忌和说明。
本地新建日程当前不支持重复规则、提醒通知或后台闹钟；输入法依赖共享实体键盘，应用不另做中文拼音输入法。

导入支持 `RRULE` 的 `DAILY/WEEKLY/MONTHLY/YEARLY`、`INTERVAL`、`COUNT`、`UNTIL`。
月/年重复遇到不存在的日期取当月最后一天，与完整 RFC 5545 不同。
`BYDAY` 等其他规则、`EXDATE`、`RDATE`、`RECURRENCE-ID` 事件会跳过并提示。
UTC 和 `TZID` 保留时区标记，当前不转换时区；导出的本地时间是浮动本地时间。
订阅日程在界面中标明只读，避免把修改误当作写回服务器。

## 构建与验证

由统一 `apps/CMakeLists.txt` 构建，不单独部署原桌面：

```cmake
add_executable(c1max-calendar
  calendar/src/main.cpp calendar/src/calendar_model.cpp calendar/src/calendar_store.cpp
  shared/display.cpp shared/keyboard.cpp)
target_include_directories(c1max-calendar PRIVATE shared)
target_link_libraries(c1max-calendar c1net lvgl m)
```

共享中文字体：`/storage/apps/current/shared/NotoSansSC-Regular.ttf`，Tiny TTF 以 `A:` 文件路径加载。
前台进程和原装桌面的退出/恢复继续由 launcher 监督器管理。

```sh
sh apps/calendar/tests/run.sh
```

离线 ASAN/UBSAN 测试覆盖：1900–2199 所有月份、闰年、DST/2038、公历边界、ICS 解析、
本地日程数据往返、编辑/删除、输入校验、重复标识、容量限制、私有文件权限、原子持久化、损坏文件保护，
以及 ICS 导出/折行/再导入。0.3 新增预设默认停用、旧数据保留、URL 去重、删除后不重建、
16 来源容量与已满时仍可编辑已有来源的测试。程序支持 `--version` 和 `--smoke-ms 1..60000`。

2026-09-23：原版七个公开地址实测 HTTP 200，当前均小于 256 KiB；实际 ICS 在主机
ASAN/UBSAN 解析通过，2026 年分别包含 39/27/28/22/42/19/365 个事件，无规则跳过。
日程数量和网络可达性会随外部来源更新变化。设备测试结果另记录在 `docs/` 的验收文件中。
