# 2026-10-10：游戏息屏、NES 唤醒和操作提示

## 现场与判断

用户报告游戏中黑屏，短按电源可以继续同一局，之后出现无声和异常加速。初次读取时 NES 进程仍在、背光为 10，原厂 `sys.backlight.timer=1200000`、`sys.backlight.lock=0`，输入／音量辅助进程存活。随后 USB/ADB 消失，用户唤醒后电脑暂未重新枚举到设备。

最初黑屏的 suspend/resume 内核日志已不在环形缓冲中，不能把原始触发点写成已经真机复现。后续取得了受控挂起／唤醒的完整日志，结果见下。原厂 PowerManager 的本地反汇编确认背光和挂起分别消费 `sys.backlight.timer.reset`、`sys.suspend.timer.reset`；已有辅助程序只通知前者，且直接写 sysfs 点亮背光不等于恢复电源管理器状态。

NES 原代码只要 PCM 句柄非空就停止软件限速。声卡唤醒后若不再提供正常写入背压，会导致异常加速；不可恢复写入错误则永久关闭声音。两条路径均已修正。

## 改动

- Launcher 0.3.1 对 NES、PCSX4all、DOSBox 的前台子进程会话持有 vendor PowerLock 的 `suslock` 和 `bllock`。两项都收到 ACK 才算成功，每 5 秒检查；失败关闭整个连接并重试。退出时重置空闲计时并解锁，不改用户的计时和全局锁属性。Socket 不传给游戏，launcher 崩溃也会关闭连接。
- 共享活动通知同时重置背光和挂起计时。
- NES 0.2.2 每次 VBlank 都使用与 InfoNES CPU/APU 周期匹配的独立约 60 Hz 计时（避免直接取整 60 Hz 逐渐耗尽音频缓冲），声音可用与否都生效。BOOTTIME 检测超过 0.5 秒输出间隔并重建 PCM；其他输出错误每 2 秒重试，停止应用后不再重试。重开时继续读取系统音量，不解除用户静音。
- NES 默认左右边栏为实体按键提示。`T` 切换触摸按钮，并记住选择；实体提示模式不保留隐形触摸热点，切换只绘制边栏，不清空中间游戏画面。

## 已完成验证

- macOS ASan/UBSan 音频回归：音量、短写、错误恢复、重试间隔、休眠间隔重开、保留静音、显式停止后不重开、无声／声卡不阻塞时限速，以及正常阻塞不重复降速。
- Linux socket fixture：真实生产代码的 NUL/PID/ACK 协议、失败、重连、部分成功释放、重复释放与游戏范围；既有 PowerLock 超时／断线回归通过。
- MIPS 交叉编译完整应用通过；QEMU 执行 NES 音频与实际 CPU／APU／显示测试通过。边栏切换验证中间 framebuffer 像素未变化，隐藏触摸按钮不触发游戏动作。
- 使用实际 MIPS 渲染代码和打包字体生成边栏排版预览并检查。此图中间是黑色测试背景，不是运行游戏的真机截图，没有替换 README 真机截图。

## 真机部署与验证

- 正式安装 Launcher 0.3.1 / NES 0.2.2 至 `/storage/apps/releases/20261010-211117-3c4de9a8`；570 个文件逐项 SHA-256 校验后切换 `current`，保留旧 release 和用户数据。应用商店中使用内置版本的条目同步版本／摘要，保留安装、首页显示选择及独立安装的覆盖版本。
- 从同一组生产目标文件链接只读 PCM 统计包装器，在隔离 QA 菜单运行用户提供的《坦克大战》。默认实体按键提示、`T` 切换触摸按钮再切回均经真机截图确认，偏好保存为 `keys`。用户确认“能听到，速度也正常”。统计包装器不进入正式应用或公开包。
- 稳定运行区间 78.19 秒，实际成功写入约 44,107.7 PCM 帧／秒，无音频欠载。该指标用于检查音频节奏，不冒充液晶实际刷新率测量。
- 暂停输入／音量辅助进程，把息屏阈值临时设为 8 秒：连续 30 秒无输入时的 15 次采样中，背光均为 12，游戏会话的挂起锁保持有效。随后恢复原 1,200,000 毫秒计时和辅助进程；全局背光／挂起锁属性均保持 0。
- 通过 `rtcwake -m mem` 执行一次真实挂起／唤醒，内核记录设备 suspend/resume，原游戏 PID 未变。原计划 6 秒后 RTC 唤醒，实际约 1.77 秒返回，属于提前唤醒，不计为完整 6 秒休眠。NES 记录 `resume/output gap; reopening PCM`，新 PCM trigger 时间和指针确认输出已重建，扬声器路由重新打开；音量保持用户调整的 116/116。
- 恢复后连续 180.29 秒约 44,107.9 PCM 帧／秒，无音频欠载；再次开始游戏／射击后采样非零。用户听感确认来自本次测试会话，但没有单独确认挂起前后音色完全一致，不声称已覆盖所有游戏或长期休眠。

退出测试时向 GPIO 电源键注入长按后 USB/ADB 再次断开，尚未确认退出后的锁释放及正常 launcher 恢复；这项保留待设备唤醒后检查，不能据上述结果宣称所有黑屏问题已解决。设备的临时 QA 程序也待连接恢复后清理。

本地构建和测试输出保存在忽略目录 `.build/nes-resume-20261010/`。不包含在公开应用包里。
