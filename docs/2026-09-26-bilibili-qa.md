# Bilibili 首版验证（2026-09-26 至 09-27）

目标设备：C1 Max / MIPS32r2 / Linux 4.4，逻辑分辨率 800×340。
参考 wiliwili 提交 `88e5876bea9502d06f46a8656e3530684d3aaf7d`。

## 2026-09-27 联网复测（0.1.1）

- Wi-Fi 恢复后，原生 MIPS API 在真机取得热门 20 条、搜索 processing
  20 条、详情／分 P、360p MP4、PNG 封面，以及登录二维码；轮询返回
  86101（等待扫码）。GUI 热门和真实搜索结果已重新截图。
- 复现旧版 403：原厂 MPlayer 的 HTTPS 请求没有接收到普通 `-referrer`
  参数。同一新鲜直链，wget 成功、旧播放器失败；补充 `-lavfstreamopts`
  后成功解码。错误提示也改为“服务器拒绝访问（403）”，不再断言链接过期。
- 发现原厂 HTTPS 流的 seek 会触发 SIGBUS：带缓存、不带缓存、MOV demuxer
  和启动时 `-ss 15` 均复现；同一视频的 HTTP Range 和本地文件跳转成功。
  当前视频走同一白名单 CDN 的原生 HTTP 通道，保留完整路径和签名查询串。
  **视频传输不加密**；API、扫码登录、封面仍走 HTTPS，不向 CDN 发送账号 Cookie。
- `pausing_keep_force seek` 换成 `pausing_keep seek`，使暂停时的跳转实际执行，
  完成后保持暂停；查询进度仍使用 force 前缀。异常退出不再冒充正常播放结束。
- 新增真机专用 `c1max-bilibili-player-test`：使用真实 Player、MPlayer、CDN、
  YUV FIFO 和完整帧读取，仅以空显示端替代 framebuffer，始终静音、不读键盘。
  两个公开视频 BV1XLhd6tE23、BV14Dho6WE66 均通过：暂停帧数／时间保持不变；
  暂停跳至 15 秒后新帧保持；恢复帧数和时间推进；向前至 70 秒及向后至 5 秒。
  这是播放器集成回归，不替代触摸或显示验证。
- 有声 GUI 连续播放约 40 秒，稳定区间每 5 秒增加 149–151 帧，约 30 fps；
  一段出现短暂缓冲。两张独立 framebuffer 截图显示不同画面。用户确认“有声音了”；
  尚未测量精确音画同步或长时间稳定性。
- GUI 客户端 RSS 约 4.3–5.1 MB；另有 MPlayer 解码、缓存、音频进程，不能把
  客户端 RSS 当作整套播放器内存。QA 早期在 RAM 的 `/tmp` 积累 21 张原始截图，
  恢复原装桌面后曾触发 OOM。已将截图移回电脑并清除设备临时副本及多余测试程序，
  后续测试先停止原装桌面，两个播放器回归均通过。正式应用不保存这些原始截图。
- MIPS API 回归与 YUV 缩放 ASan/UBSan 回归再次通过。公开包不包含测试二进制、
  QA 数据、私有账号或 Tox；设备本地包继续保留已有 Tox。

## 首版已通过（历史）

- 全部原生应用交叉编译通过；Bilibili 静态 MIPS ELF 约 2.4 MB。
- MIPS API 回归通过：WBI 签名、ID 提取、UTF-8 截断、CDN URL 边界、
  登录 Cookie 作用域、错误码保留、DASH-only/缺凭据拒绝。
- 同一个 MIPS API 实现在电脑的 QEMU 中连接真实 B 站：热门 20 条、
  搜索 processing 20 条、详情/分 P、360p 合并 MP4 播放源、PNG 封面，
  以及二维码生成、轮询 `86101`（等待扫码）全部成功。
- 真实公开视频的原始码流：H.264 640×360 30fps + AAC，未转码。
  450 帧真机无显示解码基准约 6.684 秒（不能直接当成屏幕帧率）。
- 原始视频截取 20 秒，以文件方式在真机完成静音 GUI 播放。
  5/10/15 秒分别收到 138/284/430 帧，约 28–29fps；客户端 RSS
  4356 kB（不含 MPlayer）。两次独立 framebuffer 截图显示不同视频画面。
- 真机暂停期间帧数保持 74；修复 MPlayer `pause` 命令后，恢复播放
  帧数继续增加。Fit 切换和控制条截图无拼接破碎。
- 真机搜索框输入 `bili`，右上 Backspace 后截图显示 `bil`；返回结束编辑，
  电源键退出。没有屏幕键盘。
- 真实共享 YUV 适配器在 AddressSanitizer/UBSan 下通过：原尺寸逐像素一致、
  640×360/360×640 可选缩放、缩放像素映射、默认拒绝 360p、超限拒绝。
- 原有 StreamPlayer 回归通过：完整帧、视频布局/控制条、HLS 边界/时间线、
  VTT/PGS 字幕、字幕线程/取消等。
- 图标 RGBA，alpha 范围 0..255；放入公开 Launcher 资源，完整提示词已保存。
