# 五子棋

15×15 自由规则五子棋：黑先，任意方向五子或以上连线获胜，无禁手。支持人机、同机双人、悔棋和自动续局。电脑会优先取胜／堵住对手的四连，再按开放棋形选择落点；是轻量休闲对手，不是专业棋力引擎。

- WASD 移动光标；右下回车或空格落子。
- 触屏先选择交点，再按大号“落子”按钮，避免小棋盘误触。
- U 悔棋：人机撤回最近一轮，双人撤回一手。
- N 新棋局；M 切换模式。已有棋局时需确认，返回键取消。
- 短按电源回应用菜单。没有声音。

每次落子／悔棋原子保存到 `$C1_APPS_DATA/gomoku/game.txt`（默认 `/storage/apps/data/gomoku/game.txt`）；升级不覆盖。重新打开自动续局。

运行 `sh gomoku/tests/run.sh` 检查四方向胜负、越界、AI 必胜／防守、悔棋、存档非法输入和自对弈终局。界面复用项目物理键盘和 LVGL framebuffer 适配。
